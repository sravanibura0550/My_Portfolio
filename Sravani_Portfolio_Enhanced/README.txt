SRAVANI BURA PORTFOLIO — ENHANCED VERSION

FILES
- index.html: portfolio structure
- style.css: original design + light theme + assistant styling
- script.js: interactions, fixed preloader, theme toggle, portfolio assistant

ADD YOUR PERSONAL FILES
1. Put your own profile photo in this folder and name it exactly: photo.png
   (The same image appears in the hero and About section.)
2. Your CV is already included as cv.pdf. Both Download CV buttons download this file.
   Replace cv.pdf with a newer PDF later if you update your resume.
3. Keep index.html, style.css, script.js, photo.png and cv.pdf in the SAME folder.

RUN
- Open this folder in VS Code.
- Install/enable Live Server if needed.
- Right-click index.html > Open with Live Server.

THEME
- The default dark theme keeps the existing original palette.
- Click the sun/moon button in the navbar to switch themes.
- The selected theme is saved in this browser.

ASSISTANT NOTE
The included portfolio assistant is a local, keyword-based FAQ assistant. It answers common questions from the portfolio content and does not call Gemini/OpenAI or require an API key. For a generative AI assistant, a secure backend and API key configuration are needed.
